# منصة الاختبارات — المعهد العالي للعلوم والتقنية القره بوللي

مشروع بداية متكامل: HTML/CSS/JS + Cloudflare Pages Functions + Cloudflare D1.

## المزايا
- واجهة عربية RTL ومتجاوبة.
- إنشاء حساب طالب وتسجيل الدخول والخروج.
- جلسات موقعة بـ HMAC، وكلمات مرور مشتقة عبر PBKDF2.
- قائمة مواد وأسئلة من قاعدة البيانات.
- اختبار مؤقت، تصحيح من الخادم، وحفظ النتيجة. يتم حفظ مجموعة أسئلة جلسة الاختبار في الخادم لمنع تقليل عدد الأسئلة المرسلة عند التسليم.
- لوحة مدير لإضافة/حذف الأسئلة وعرض المستخدمين ونتائجهم.
- صلاحيات المدير تُفحص على الخادم، لا من واجهة المتصفح فقط.

## متطلبات قبل النشر
1. حساب Cloudflare.
2. إنشاء قاعدة D1 وربطها بالمشروع باسم binding: `DB`.
3. تطبيق مخطط `migrations/0001_init.sql`.
4. تعيين سر `SESSION_SECRET` من إعدادات Pages > Settings > Variables and Secrets.
5. نشر المشروع من Git أو باستخدام Wrangler. الرفع المباشر Drag & Drop لا يدعم تشغيل Pages Functions بالطريقة نفسها؛ استخدم Git integration أو Wrangler للمشروع الذي يحتوي `functions/`.

## إعداد قاعدة البيانات
من Cloudflare Dashboard:
- Workers & Pages > D1 SQL Database > Create database.
- سمّها مثلًا `quiz-platform-db`.
- افتح Console وشغّل محتوى `migrations/0001_init.sql`.
- اربط قاعدة البيانات بمشروع Pages في Settings > Functions > D1 database bindings، واجعل Variable name هو `DB`.

## إعداد سر الجلسات
أضف `SESSION_SECRET` كـ Secret في إعدادات المشروع، واجعله قيمة عشوائية طويلة (32 بايت أو أكثر). لا تضعه في ملفات الموقع أو Git.

## حساب المدير الأول
لا يوجد حساب مدير افتراضي ولا كلمة مرور ثابتة عمدًا.
بعد إنشاء أول حساب من الموقع، غيّر دوره يدويًا من D1 Console:
```sql
UPDATE users SET role = 'admin' WHERE username = 'اسم_المستخدم_الذي_أنشأته';
```
نفّذ الأمر مرة واحدة لحساب تثق به فقط.

## تطوير محلي
يتطلب Wrangler. بعد تثبيت Node.js:
```bash
npm install -g wrangler
wrangler login
wrangler pages dev public --d1 DB=quiz-platform-db --compatibility-date=2026-10-26
```
لربط قاعدة محلية أو إنتاجية، راجع توثيق Wrangler وD1 لأن أوامر قاعدة البيانات تختلف حسب البيئة.

## هيكل المشروع
- `public/` واجهة المتصفح.
- `functions/api/` مسارات الخادم.
- `functions/_lib/` مصادقة ومساعدات مشتركة.
- `migrations/0001_init.sql` جداول قاعدة البيانات وبيانات المواد الأولية.

## ملاحظات أمان
- هذا مشروع تأسيسي قابل للتشغيل بعد إعداد D1 وSecrets؛ اختبره قبل استخدامه رسميًا.
- لا تضع بيانات شخصية حساسة في بيئة تجريبية.
- أضف سياسة خصوصية وشروط استخدام ونسخًا احتياطية قبل الإطلاق الرسمي.
- يجب تغيير سر الجلسة إلى قيمة قوية، وترقية حساب المدير فقط من لوحة قاعدة البيانات.
- أسئلة الاختبار والإجابات الصحيحة تُرسل للعميل عند بدء الاختبار فقط كجزء من تصميم هذه النسخة؛ في الامتحانات عالية الأهمية يفضّل اعتماد تدفق جلسة امتحان أقوى ومراجعة أمنية مستقلة.
